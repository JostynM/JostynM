## 🚀 Proyectos destacados

### 🎵 NOVALT — Landing Page para Productor Musical

Landing page responsive desarrollada para presentar la identidad, servicios, producciones y beats de un productor musical.

**Lo que trabajé:**
- Diseño responsive para desktop, tablet y móvil.
- HTML, CSS y JavaScript modular.
- Animaciones con **GSAP + ScrollTrigger**.
- Menú hamburguesa y navegación por secciones.
- Integraciones con YouTube, Spotify, BeatStars y WhatsApp.
- Build con **Vite** y despliegue en **Vercel**.

### 🛒 Sistema de Gestión de Ventas e Inventario — SQL Server

Base de datos relacional desarrollada para gestionar clientes, productos, pedidos, pagos, empleados, sucursales, proveedores e inventario.

**Lo que trabajé:**
- Diseño de tablas, claves primarias y foráneas.
- Restricciones `UNIQUE`, `CHECK` y valores `DEFAULT`.
- Consultas con `JOIN`, subconsultas, CTE, `GROUP BY`, `HAVING` y funciones de ventana.
- Vistas, funciones y procedimientos almacenados.
- Triggers para control automático de stock.
- Transacciones con `COMMIT`, `ROLLBACK`, `TRY/CATCH` y `THROW`.
- Carga masiva, backup y documentación técnica.
